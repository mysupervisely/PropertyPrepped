# Tester feedback: back swipe and county records

The existing iOS shell leaves WKWebView's back/forward gesture disabled. IOSBackSwipe provides a web-delivered left-edge gesture in that shell, using existing history.back navigation. It is native-iOS-only, not an override of Safari gestures. A rightward swipe must start within 24 CSS pixels of the left edge, travel at least 72 pixels, stay within 36 pixels vertically, and finish in 50-900 ms. Controls, open dialogs/overlays, multi-touch, cancelled gestures and vertical scrolls are excluded. Existing property-back unsaved-condition checks still run through popstate. Tabs without history entries still return to the dashboard, not to the previous tab. Remove this fallback if a future shell enables native WKWebView gestures to avoid double navigation.

Public property information is available for every saved property, across all 50 states. Florida addresses link to the Florida Department of Revenue county-official directory; other addresses use the verified USAGov local-government directory, which lists all 50 states and DC. Municipal assessors are included in the instructions because assessment is not always administered at county level. Address copying and Update property facts support a manual lookup. This is not automatic county data importing. No new requests to paid data providers, scraped records, inferred parcel matches, or automatic overwrites are introduced. County assessments and market resale estimates are explicitly distinguished. Missing or incomplete state information falls back to the nationwide directory.

Sources checked: Apple WKWebView allowsBackForwardNavigationGestures documentation; Florida DOR LocalOfficials.aspx; Leon County Property Appraiser leonpa.gov; USAGov usa.gov/local-governments. The existing RentCast valuation adapter deliberately omits subject-property facts because AVM comparables describe other properties; its separate Property Records request is not enabled by this change.

Validation: gesture direction/timing tests and event integration tests cover browser/Android exclusion, one history action, listener cleanup, overlays, scrolling and multi-touch. Production Next.js build passed. Physical iPhone swipe feel remains a tester/device acceptance check. No native binary change is required for this web-delivered gesture.
