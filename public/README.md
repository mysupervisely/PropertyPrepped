# hero-property.jpg

Formerly the signed-out landing page's (`/`) hero background. As of
Public Homepage V2 (Product Story + Pricing Simplification), the hero no
longer uses a house photo as PropRoster's primary visual identity — it's
a calm brand-toned gradient instead (`app/globals.css`'s `.landingHero`
rule). This file is kept, unreferenced, in case a future pass wants to
reintroduce photography deliberately; nothing currently loads it.

Current file: a warm, dusk-lit, contemporary single-family home — no
people, no identifiable street address, optimized to ~220KB (resized to
1536px wide, progressive JPEG, quality 78 via `sharp`) from a larger
source.
